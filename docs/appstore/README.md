# Ласточка в App Store (и единый выпуск на все платформы)

Один запуск «Ласточка (Android, iPhone, Windows, macOS)» выпускает всё сразу:

| Где | Как доходит до людей |
|---|---|
| Windows, macOS, Android (APK) | выпуск на GitHub → Ласточка обновляется сама, в течение часа |
| Google Play | этап `stores` загружает AAB на дорожку `PLAY_TRACK` → выходит после проверки Google (часы) |
| App Store | этап `ios-appstore` выгружает сборку в TestFlight, этап `stores` отправляет её на проверку Apple → выходит сама после одобрения (обычно до суток) |

Выпуск на GitHub ждёт успешной сборки всех платформ, в том числе iPhone для App Store, а в магазины
отправляется только то, что опубликовано на GitHub. Точно в одну минуту выйти не получится: Google и Apple
проверяют каждое обновление сами. Обычно всё выходит в течение суток. Пока не заданы секреты магазина,
он просто пропускается, остальной выпуск идёт как раньше.

Файлы: `.github/workflows/mobile.yml` (этапы `ios-appstore` и `stores`),
`mobile/tool/appstore_prepare.py` (настройка iOS-проекта), `mobile/tool/ios/appstore/AppDelegate.swift`
(уведомления Apple), `mobile/tool/store_publish.py` (отправка в Google Play и App Store).

## 1. Один раз: аккаунт и ключи Apple

1. **Apple Developer Program** (99 $ в год): https://developer.apple.com/programs/enroll/.
   Понадобится Apple ID с двухфакторной защитой; для организации — номер D-U-N-S.
2. **Team ID** — https://developer.apple.com/account → Membership details → Team ID (10 символов).
3. **Ключ App Store Connect API** — https://appstoreconnect.apple.com/access/integrations/api →
   «Team Keys» → «+». Роль — **Admin** (с меньшей ролью Xcode не сможет сам создать сертификат
   распространения). Скачайте `AuthKey_XXXXXXXXXX.p8` — скачать его можно только один раз.
   Запишите **Key ID** и **Issuer ID** (вверху страницы).
4. **Секреты в GitHub** — репозиторий → Settings → Secrets and variables → Actions → New repository secret:

   | Секрет | Что вписать |
   |---|---|
   | `APPLE_TEAM_ID` | Team ID |
   | `ASC_KEY_ID` | Key ID ключа |
   | `ASC_ISSUER_ID` | Issuer ID |
   | `ASC_KEY_P8` | всё содержимое файла `AuthKey_….p8`, включая строки `-----BEGIN/END PRIVATE KEY-----` |

5. **Приложение в App Store Connect** — https://appstoreconnect.apple.com/apps → «+» → «Новое приложение»:
   - платформа iOS, название «Ласточка» (если занято — «Ласточка мессенджер»);
   - основной язык: русский;
   - Bundle ID: **`app.lastochka.lastochka`** (тот же, что у Android). Если его нет в списке — один раз
     запустите сборку (шаг 2): Xcode зарегистрирует его сам вместе с правом на push-уведомления.
     Можно и вручную: developer.apple.com → Identifiers → «+» → App IDs, отметьте Push Notifications;
   - SKU: `lastochka`.
6. **Уведомления на iPhone** (когда Ласточка закрыта) идут через тот же шлюз Sygnal, что и для Google Play.
   - developer.apple.com → Keys → «+» → отметьте **Apple Push Notifications service (APNs)** →
     скачайте `AuthKey_….p8` и запишите его Key ID. Это другой ключ, не ключ App Store Connect.
   - На сервере шлюза положите его как `/opt/push/sygnal/apns-lastochka.p8` и ещё раз запустите
     `server/setup-push-server.sh` (он спросит Key ID и Team ID). Шлюз подключит `app.lastochka.ios`.
   - Секрет `PUSH_GATEWAY` уже задан для Google Play, сборка для App Store берёт его же.

   Apple показывает уведомление «Ласточка: Новое сообщение» без имени и текста: переписку Apple не
   видит, как и Google. Входящий звонок тоже придёт таким уведомлением. Нажмите на него, и Ласточка
   откроет звонок, если он ещё идёт.

## 1а. Один раз: Google Play

1. Play Console → «Настройка» → «Доступ к API» (или Google Cloud → IAM) → создайте **сервисный аккаунт**,
   скачайте его ключ JSON.
2. Play Console → «Пользователи и разрешения» → «Пригласить» → почта сервисного аккаунта →
   доступ к приложению Ласточка с правом «Выпуск приложений на тестовые и рабочие дорожки».
3. Секрет GitHub **`PLAY_SERVICE_ACCOUNT`** — всё содержимое файла JSON.
4. Переменные GitHub (Settings → Secrets and variables → Actions → **Variables**):
   - **`PLAY_TRACK`** — куда идут обычные выпуски. Пока приложение на тестировании, поставьте дорожку
     тестирования: `internal` (внутреннее) или `alpha` (закрытое). После выхода в общий доступ —
     `production` (это значение по умолчанию, если переменная не задана);
   - `PLAY_BETA_TRACK` — для выпусков с галочкой «Тестовая версия» (по умолчанию `beta`, открытое тестирование).

Номер сборки (versionCode) — номер запуска в GitHub. Он всегда растёт, так что новые выпуски
продолжают нынешнюю 4.19.54 из Play без ручной правки.

## 2. Выпуск

Actions → «Ласточка (Android, iPhone, Windows, macOS)» → Run workflow → версия, при желании
**«Что нового»** (уйдёт в Google Play и App Store) → Run. Дальше всё идёт само, как описано в таблице выше.

- **Тестовая версия** (галочка «beta»): GitHub (пре-релиз) + Google Play `PLAY_BETA_TRACK` + TestFlight,
  на проверку Apple не отправляется.
- Если прежняя версия ещё ждёт проверки Apple, она снимается с проверки и заменяется новой.
- **Самый первый выпуск в App Store** скорее всего остановится на отправке на проверку: Apple ещё не
  хватает описания, скриншотов и анкет (раздел 4). Сборка к версии уже будет прикреплена:
  дозаполните страницу и нажмите «Отправить на проверку» вручную. Следующие выпуски пойдут сами.

Перед первым выпуском проверьте сборку через TestFlight на своём iPhone: вход, расшифровка старых
сообщений, уведомление при закрытой Ласточке, звонок (в том числе со свёрнутой Ласточкой), голосовые,
фото, Face ID, код-пароль.

## 3. Что уже сделано в проекте для правил Apple

- **Только iPhone.** Для iPad Apple требует отдельные скриншоты и все повороты экрана. На iPad
  приложение для iPhone всё равно запускается.
- **Звонки в фоне.** Включён режим `audio`, чтобы звонок не обрывался, когда Ласточку свернули.
- **Шифрование.** `ITSAppUsesNonExemptEncryption = NO`: используются только стандартные открытые
  алгоритмы (Olm/Megolm через vodozemac, AES в SQLCipher, TLS), и приложение массового рынка
  (освобождение EAR 740.17(b)(1)) — так же делают другие Matrix-клиенты. Тогда App Store Connect
  не спрашивает про экспорт при каждой сборке. Решение юридическое и остаётся за вами: если
  сомневаетесь, удалите ключ в `appstore_prepare.py` и один раз ответьте на анкету в App Store Connect.
  Для продажи во Франции Apple может попросить отдельную декларацию.
- **Уведомления через Apple (APNs)**: право `aps-environment`, ключ устройства из `AppDelegate.swift`,
  регистрация на сервере Matrix (`lib/system/push.dart`, только при `--dart-define=APPSTORE=true`).
  Пока Ласточка открыта, уведомление Apple не показывается: она сама показывает своё, с именем.
- **Манифест конфиденциальности** `PrivacyInfo.xcprivacy`: без слежки (tracking), данные
  разработчику не уходят, указаны причины доступа к настройкам (UserDefaults) и датам файлов.
- **Нет самообновления.** На iPhone оно и раньше было выключено (`Updater.supported`), поэтому пункты
  «Обновлять самостоятельно» и «Тестовые версии» на iPhone не показываются.
- **Жалобы и блокировка** (обязательны по правилу 1.2 для переписки): «Пожаловаться администратору»
  и «Заблокировать отправителя» в меню сообщения, список — «Настройки → Заблокированные».
- **Удаление аккаунта** (правило 5.1.1(v)) не требуется: в приложении нельзя создать учётную запись,
  её выдаёт администратор сервера. Так и ответьте ревьюеру, если спросит.

**Цена:** бесплатно

**Подзаголовок** (до 30 символов):
> Защищённый Matrix-мессенджер

**Ключевые слова** (до 100 символов, через запятую без пробелов):

**Описание:**
> Ласточка — защищённый мессенджер на открытом протоколе Matrix. Подключается к серверу Matrix

>

> • Голосовые и видеозвонки, голосовые сообщения и «кружки»
> • Фото, видео, файлы, стикеры и эмодзи
> • Закреплённые сообщения, ответы, ветки, поиск
> • Код-пароль и Face ID, скрытие содержимого в списке приложений

> • Без рекламы и без сбора статистики
>
> Учётную запись выдаёт администратор сервера Matrix.

**Рекламный текст** (до 170 символов, меняется без проверки):
> Переписка и звонки со сквозным шифрованием на вашем сервере Matrix — без рекламы и слежки.

**Возрастной рейтинг:** в анкете укажите «Общение пользователей / пользовательский контент — да».
Обычно получается 13+ или 16+, в зависимости от остальных ответов.

**«Конфиденциальность приложения» (App Privacy):** «Мы не собираем данные». Разработчик ничего не
получает, переписка идёт на сервер, который выбирает пользователь. ⚠️ Поиск GIF уходит в GIPHY (если
задан `GIPHY_KEY`): текст поиска передаётся третьей стороне. Честнее указать «Содержимое,
созданное пользователем → поисковые запросы, не связаны с пользователем, не для отслеживания» и
дописать об этом в политику конфиденциальности, а можно не задавать `GIPHY_KEY` в App Store-сборке.

### Скриншоты

Скриншоты из Google Play (1080×1920) не подходят. Нужно от 3 до 10 штук для iPhone **6,9"** —
1320×2868 или 1290×2796 (портрет), PNG или JPG без прозрачности. Проще всего снять их в
симуляторе iPhone 16/17 Pro Max (⌘S в Simulator) или на таком iPhone. Остальные размеры
App Store Connect сделает сам. Не показывайте на скриншотах настоящую переписку и личные данные.

## 5. Отправка на проверку (App Review)

В разделе версии → «Информация для проверки приложения»:

- **Нужен вход: да.** Создайте на своём сервере Matrix **тестовую учётную запись** с парой чатов
  (один зашифрованный) и укажите логин целиком (`@review:ваш-сервер`) и пароль. Без рабочего
  входа Apple отклоняет приложение (правило 2.1).
- **Заметки для проверяющего** (можно по-английски):
  > Lastochka is a client for the open Matrix protocol. Accounts are issued by the administrator of a
  > Matrix homeserver; the app has no in-app sign-up, so account deletion is done by the server admin.
  > Enter the full login (@review:server) — the server is detected automatically.
  > Users can report any message (long press → "Пожаловаться администратору") and block the sender
  > ("Заблокировать отправителя"); blocked users are listed in Settings → "Заблокированные".
  > Calls: start a call in the chat "Test" — a second test account answers if needed.
  > The app uses only standard encryption (Olm/Megolm, AES, TLS).
- Контакты для связи: имя, телефон, почта.

Возможные замечания Apple и ответы на них:
- *«Приложение только для одной организации — используйте Apple Business Manager (правило 3.2)».*
  Ответ: это универсальный клиент Matrix, работает с любым сервером Matrix, сервер вводится при входе.
- *«Фоновый режим audio не используется» (2.5.4).* Ответ: он нужен, чтобы звонок продолжался в фоне;
  покажите это в видео (запись экрана во время звонка со свёрнутым приложением).

## 6. Что можно улучшить потом

- **Входящий звонок как в «Телефоне»** (экран звонка на заблокированном iPhone): PushKit + CallKit.
  Нужны отдельный тип уведомлений в Sygnal (`push_type: voip`) и нативный код звонка.
- **Имя и текст в уведомлении**: Notification Service Extension, которое само расшифровывает
  сообщение на iPhone. Это отдельная программа внутри приложения, ей нужен доступ к ключам Ласточки.
- **Счётчик на значке**: сейчас его обновляет только открытая Ласточка.
