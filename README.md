# Ласточка 🕊

Защищённый Matrix-мессенджер в стиле Telegram для macOS и Windows.
Сквозное шифрование как в Element, эмодзи и стикеры, голосовые, закрепы, поиск, код-пароль,
управление сеансами и экспорт ключей. О защите — в `SECURITY.md`.

## Сборка на Mac
Нужен Node.js 20+ (https://nodejs.org, LTS). Дважды щёлкните **«Собрать Ласточку для Mac.command»**
(если macOS не пускает — правый клик → «Открыть»). Или в Терминале:
```bash
cd lastochka
npm install && npm run harden && npm run dist
```
В `release/` появятся `Lastochka-3.0.0-arm64.dmg` и `SHA256SUMS.txt`.

## Сборка на Windows
Дважды щёлкните **«Собрать Ласточку для Windows.bat»** или выполните
`npm install && npm run harden && npm run dist:win`.
Получите `Lastochka-Setup-3.0.0.exe` (установщик) и `Lastochka-3.0.0-portable.exe`.
SmartScreen при первом запуске: «Подробнее» → «Выполнить в любом случае».

## Обновление
Раз в месяц пересобирайте: `npm run harden && npm run dist` — так подтягиваются
исправления безопасности Electron/Chromium.

## Переход со старого «Matrix Chat»
Ласточка — новое приложение со своим защищённым хранилищем, поэтому вход нужен заново:
1. В старом приложении убедитесь, что резервная копия ключей включена (или сделайте ☰ → «Экспорт ключей»).
2. Войдите в Ласточку и подтвердите вход ключом восстановления.
3. В Ласточке: ☰ → «Мои сеансы» → завершите сеанс «Matrix Chat (macOS)».
4. Удалите старое приложение и его папку `~/Library/Application Support/Matrix Chat`
   (на Windows `%APPDATA%\Matrix Chat`) — там ключи лежали без шифрования.

## Если что-то не так
- Электрон не скачивается — скрипты уже используют зеркало npmmirror; можно включить VPN.
- «Приложение повреждено» на Mac: `xattr -cr /Applications/Ласточка.app`.
- При первом запуске после пересборки macOS может спросить доступ к Связке ключей
  «Ласточка Safe Storage» — нажмите «Разрешать всегда».
